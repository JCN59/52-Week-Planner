# Project: World Cup 2026 Tracker

**Status:** active · **Repo:** `jcn59/52-week-planner` (main app in repo root)

## Goal
A plain-English 2026 World Cup tracker for non-soccer-fans: daily Claude-written
briefing, live ESPN scores, groups, bracket, rankings, schedule.

## Stack
Next.js 14 + TypeScript + Tailwind; Claude API for the daily briefing (mock
fallback without a key); ESPN public API for live data.
