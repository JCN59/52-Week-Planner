# Business

One subfolder per business, brand, or client. Keep them isolated: when working on
one, don't read the others unless the task explicitly spans them.

- `stargazer/` — StarGazer apparel brand (pre-seeded; confirm in the interview).
- Add more as needed, e.g. `tmes/` if that's a business of yours, one folder per
  client if you do client work. Use `60-templates/client.md` for new client folders.

Financial figures and customer data stay in `70-private/` or out of the vault.
