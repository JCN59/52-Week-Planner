# Private

Everything in this folder except this README is **git-ignored** (see `vault/.gitignore`)
and stays on this machine only.

Put here: exact financials, customer data, health details, anything you'd never
want in a repo — even a private one. Agents: never quote this folder's contents
into commits, PRs, artifacts, emails, or anything else that leaves the machine.
Credentials don't belong here either — they stay in a real secret manager.

Note: because it's git-ignored, this folder does NOT sync between machines.
