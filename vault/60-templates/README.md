# Templates

Skeletons for new notes. Copy into the target folder and fill in; don't edit the
template itself unless improving the template is the task.

- `project.md` — new project note (→ `30-projects/`)
- `client.md` — new client/business folder README (→ `20-business/<name>/`)
- `decision.md` — bigger decisions that need more than a line in `DECISIONS.md`
- `meeting.md` — meeting/call notes (→ `00-inbox/`, then file)
