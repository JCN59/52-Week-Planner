# World Cup 2026 — Beginner's Tracker ⚽🏆

A simple, plain-English tracker for the **2026 FIFA World Cup** (hosted by the USA, Canada & Mexico, June 11 – July 19, 2026). Built for people who don&apos;t follow soccer and just want to keep up.

## What it does

- **📅 Today** — a daily, plain-English update: who&apos;s looking strongest, players to watch, highlights, the buzz, and a beginner tip. Generated by Claude (with a built-in sample update if no API key is set).
- **📖 How it works** — the whole tournament explained for newcomers: the basics, the **tiers** (how teams are seeded into 4 pots), the **path to the final** (group stage → Round of 32 → 16 → quarters → the "Final Four" semis → final), host cities, and a soccer glossary.
- **🗂️ Groups** — live-style standings for all 12 groups of 4, with the top-2 qualifying spots highlighted.
- **📊 Rankings** — all 48 teams sorted by FIFA world ranking.
- **🌍 Teams** — all 48 countries with a one-line intro and a star player to watch, filterable by tier.
- **🗓️ Schedule** — the rounds, key dates, and games to circle.

## Setup

```sh
npm install
cp .env.example .env.local
# (optional) add ANTHROPIC_API_KEY=sk-ant-... for fresh AI-written daily updates
npm run dev
```

Open http://localhost:3000.

**Without an API key:** the app works fully — the "Today" tab shows a curated sample update. With `ANTHROPIC_API_KEY` set, the daily update is freshly written by Claude.

## How current is the data?

Team lists, groups, tiers, the schedule structure, and star players are accurate to the 2026 World Cup. The group **standings and early results** are a snapshot (dated in the app) of the opening days — they are not a live feed. For up-to-the-minute scores, use an official source like FIFA.com.

## Tech

- Next.js 14 (App Router) + TypeScript + Tailwind CSS
- Claude API (Opus 4.8) for the daily briefing, with a mock fallback
- All reference data lives in `lib/worldcup-data.ts`

## Project structure

```
app/
  api/briefing/route.ts   # POST: generates the daily update (Claude or mock)
  page.tsx                # tabbed UI
  layout.tsx
  globals.css             # pitch-green theme
components/
  DailyBriefing.tsx       # "Today" tab
  HowItWorks.tsx          # beginner explainer + tiers + bracket + glossary
  GroupsView.tsx          # 12 group tables
  RankingsTable.tsx       # FIFA rankings
  TeamsView.tsx           # all 48 teams + star players
  ScheduleView.tsx        # rounds + key fixtures
lib/
  worldcup-data.ts        # teams, groups, tiers, schedule, glossary
  types.ts
  prompt.ts               # Claude system + user prompt for the briefing
  mock-briefing.ts        # fallback used when no API key
```
