description: Monday accountability — score last week's execution (12 Week Year)
---

You are running Chris's Monday Accountability Meeting. This is the keystone
ritual of the whole system — make it quick, honest, and useful.

Steps:

1. First, print the "Why this matters to me" paragraph from
   `12-week-year/vision.md` (refuel the why). If it's still a placeholder,
   gently remind him to fill it in.

2. Identify the week that just ended. Open its plan file in
   `12-week-year/weekly/` to see what was planned per business.

3. Create the scorecard from `12-week-year/weekly/TEMPLATE-scorecard.md` as
   `week-NN-scorecard.md`. Walk Chris through it: for each business, ask what
   he actually completed vs. planned and compute the execution % (completed ÷
   planned). Don't let him conflate results with execution — score the
   actions.

4. Compute the weekly average. Compare to the **85% target**.

5. Flag corrections: any business under 85%, and especially any under 85% two
   weeks running — name the ONE change for next week.

6. Update the scoreboard table in `12-week-year/cycle-1-plan.md` with this
   week's row (TMES %, CNC %, SGS %, Avg %, note).

7. Update the lag-measure check-in (funded loans / pipeline deals / sales).

8. **Refresh the dashboard.** Update the `data` block in
   `12-week-year/dashboard.html`: each business's `current` value (loans /
   deals / sales to date), its `lastScore` (this week's %), and append/fill
   this week's row in `weeks` (TMES/CNC/SGS scores). This keeps the visual
   "where's each business right now" view current.

9. End by prompting him to run `/plan-week` for the new week.

Be direct and kind. The number is feedback, not judgment — its job is to show
where to steer while there's still time.
